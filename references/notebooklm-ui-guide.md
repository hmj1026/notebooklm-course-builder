# Google NotebookLM 介面導覽與按鈕操作手冊

本手冊彙整 Google NotebookLM（Gemini Notebook）介面佈局、按鈕名稱與輸入位置，供 guided mode 指引與 auto mode landmark 辨識。Auto mode 的操作與驗證迴圈以 [automation.md](automation.md) 為準。

---

## 🖥️ 三大面板核心佈局

NotebookLM 採用經典的三欄式（Three-Panel）工作介面：

```
+---------------------+-------------------------------+---------------------+
|   左側：來源面板     |       中間：對話面板           |    右側：工作室面板   |
|   (Sources Panel)   |        (Chat Panel)           |    (Studio Panel)   |
+---------------------+-------------------------------+---------------------+
| [筆記本標題]        | [對話歷史與回答氣泡]          | [音訊總覽]          |
|                     |                               |                     |
| [+ 新增來源 按鈕]   |                               | [快捷工具卡片]      |
|                     |                               | - 測驗 (Quiz)       |
| [來源核取清單]      |                               | - 學習指南          |
| - [x] Source 1      |                               | - 簡報文件          |
| - [x] Source 2      |                               | - 常見問題          |
|                     |                               |                     |
|                     |                               | [記事清單 (Notes)]  |
|                     |                               | [+ 新增記事 按鈕]   |
|                     | ----------------------------- |                     |
|                     | [ 底部對話輸入框          發送] |                     |
+---------------------+-------------------------------+---------------------+
```

## 🔘 核心區塊與按鈕對照表

### 1. 左側：來源面板 (Sources Panel)

| 介面元素 | 繁體中文名稱 | 英文名稱 | 位置與操作說明 |
|---|---|---|---|
| **新增來源按鈕** | `+ 新增來源` | `+ Add sources` | 位於左側面板頂部。點擊後開啟來源新增視窗。 |
| **貼上文字選項** | `複製的文字` | `Copied text` | 新增來源彈窗內。用於將課程大綱加入為常駐大綱來源（Course Outline Source）。貼入後點擊「插入 (Insert)」。 |
| **快速研究選項** | `快速研究` | `Fast Research` | 新增來源彈窗內（研究/搜尋標籤頁）。用於輸入來源搜尋提示詞。 |
| **深度研究選項** | `深度研究` | `Deep Research` | 新增來源彈窗內。用於多步驟自主網路研究（產出多頁深度研究報告）。 |
| **上傳檔案** | `上傳檔案` | `Upload file` | 支援 PDF、Word (.docx)、文字檔 (.txt, .md)、音訊檔等。 |
| **雲端硬碟** | `Google 雲端硬碟` | `Google Drive` | 支援 Google 文件、簡報、試算表。 |
| **網頁／YouTube** | `連結` | `Link` | 支援貼入公開網頁 URL 或 YouTube 影片連結。 |
| **來源核取方塊** | `來源選取核取方塊` | `Source checkbox` | 每個來源左側的勾選框。勾選者才會被納入對話、講義生成與引用來源中。 |
| **全選來源** | `選取所有來源` | `Select all sources` | 頂部核取方塊，可一鍵全選或取消全選所有來源。 |

---

### 2. 中間：對話面板 (Chat Panel)

| 介面元素 | 繁體中文名稱 | 英文名稱 | 位置與操作說明 |
|---|---|---|---|
| **對話輸入框** | `底部對話輸入框` | `Chat input box` | 位於中間面板最底部（提示字樣通常為「輸入問題或提示詞...」或「Ask a question about your sources...」）。所有 Draft、Review、Coverage Prompt 皆在此貼入。 |
| **發送按鈕** | `發送` | `Submit / Send` | 輸入框右側的箭頭圖示（或按鍵盤 `Enter` 發送）。 |
| **儲存至記事按鈕** | `儲存至記事` / `儲存為筆記` | `Save to note` | 位於每則 AI 回答氣泡下方（便條紙圖示）。點擊後將該回答完整存入右側工作室的「記事」區。 |
| **複製回答** | `複製` | `Copy` | 位於每則 AI 回答氣泡下方（雙重矩形圖示）。點擊複製回答全文。 |
| **來源引用標註** | `引用編號` | `Citations [1], [2]` | 回答文字內的數字角標。點擊可直接高亮對照左側來源面板中對應的文件原文段落。 |

---

### 3. 右側：工作室面板 (Studio Panel)

| 介面元素 | 繁體中文名稱 | 英文名稱 | 位置與操作說明 |
|---|---|---|---|
| **音訊總覽** | `音訊總覽` | `Audio Overview` | 右側頂部。可點擊「生成」由兩位 AI 進行對話式 Deep Dive Podcast 討論。 |
| **測驗工具** | `測驗` | `Quiz` | 快捷工具卡片。點擊後自動依據目前勾選的來源生成測驗題。 |
| **學習指南工具** | `學習指南` | `Study Guide` | 快捷工具卡片。點擊後自動生成學習核心、重點問答與複習架構。 |
| **簡報文件** | `簡報文件` / `報告` | `Briefing Doc` / `Reports` | 快捷工具卡片。生成結構化總結報告。 |
| **常見問題** | `常見問題` | `FAQ` | 快捷工具卡片。生成常見疑問與解答清單。 |
| **新增記事按鈕** | `+ 新增記事` / `+ 新增筆記` | `+ Add note` | 位於記事清單頂部。可手動新增空白記事卡片並自行寫入內容。 |
| **記事卡片選單** | `更多選項 (三點圖示)` | `More options (...)` | 每張記事卡片右上角。可進行「重新命名」、「刪除」或「匯出至 Google 文件 (Export to Google Docs)」。 |

## 📍 14 階段工作流程之精確 UI 路徑對照

為避免使用者迷失，AI 代理在輸出各階段指示時，請嚴格套用下列標準路徑描述：

| 階段 | 操作目標 | 精確操作指示格式 |
|---|---|---|
| **Phase 3** | 新增大綱為來源 | **位置**：左側「來源」面板 ➔ 點擊 **`+ 新增來源`** ➔ 選擇 **`複製的文字`**。<br>**動作**：貼入當前 Module 大綱文字，在標題處填寫「`Module X 大綱`」，點擊 **`插入`**。 |
| **Phase 4** | 執行快速研究 | **位置**：左側「來源」面板 ➔ 點擊 **`+ 新增來源`** ➔ 選擇 **`快速研究`**。<br>**動作**：將下方短版 Prompt 貼入搜尋框，按下 `Enter` 執行搜尋。搜尋完成後**展開候選清單**瀏覽，**請勿點擊匯入或全選**。 |
| **Phase 5** | 審核與匯入來源 | **位置**：快速研究候選來源視窗中。<br>**動作**：參照審核表，只勾選標記為 `Import`（及已核准可選）的項目，點擊視窗右下角 **`匯入 (Import)`** 按鈕；auto mode 由代理在 Source Import Gate 核准後操作。 |
| **Phase 6** | 涵蓋度分析 | **位置**：中間「對話」面板底部的 **`對話輸入框`**。<br>**動作**：貼入 Coverage Analysis Prompt 並按發送。確保左側所有已匯入來源皆處於勾選狀態。 |
| **Phase 7** | 補足來源缺口 | **位置**：重複 Phase 4 之快速研究路徑，或透過 `+ 新增來源` ➔ `連結` 手動貼入指定補強網址。 |
| **Phase 8** | 產生單節 Draft | **位置**：中間「對話」面板底部的 **`對話輸入框`**。<br>**動作**：貼入單節講義 Draft Prompt 並按發送。 |
| **Phase 9** | 審查講義 Review | **位置**：中間「對話」面板（**延續同一個對話串**）底部的 **`對話輸入框`**。<br>**動作**：貼入 Review Prompt 並按發送。 |
| **Phase 10** | 修訂產出 v2 | **位置**：中間「對話」面板底部的 **`對話輸入框`**。<br>**動作**：貼入 Minor Revision v2 Prompt 並按發送。 |
| **Phase 11** | Final Check 與存檔 | **位置**：中間「對話」面板底部的 **`對話輸入框`**。<br>**動作**：貼入 Final Check 指令。判定 `PASS` 後，在該則正式講義回答氣泡下方點擊 **`儲存至記事 (Save to note)`**（便條圖示），講義將保存至右側工作室的記事區。 |
| **Phase 12** | Module 整體驗收 | **位置**：中間「對話」面板底部的 **`對話輸入框`**。<br>**動作**：貼入 Module Review Prompt 並按發送。 |
| **Phase 13** | 產出 Quiz 與指南 | **位置 A**：右側「工作室」面板 ➔ 直接點擊 **`測驗 (Quiz)`** 或 **`學習指南 (Study Guide)`** 工具卡片生成。<br>**位置 B**：中間對話輸入框貼入提示詞 ➔ 生成後點擊回答下方的 **`儲存至記事`**。 |
| **Phase 14** | 開啟下一 Module | **位置**：點擊左上角返回筆記本清單 ➔ 點擊 **`+ 新增筆記本 (+ New notebook)`** 開啟新模組空間。 |

## ⚠️ 介面操作常見陷阱與防呆守則

1. **研究提示詞誤當來源**：
   - ⚠️ 錯誤：將 Fast Research Prompt 貼到「複製的文字」並按插入。
   - ✅ 正確：Prompt 只能輸入在「快速研究」的搜尋列中；大綱才可作為「複製的文字」匯入。
2. **候選來源全選匯入**：
   - ⚠️ 錯誤：快速研究完成後直接點擊「全部匯入」。
   - ✅ 正確：必須逐項勾選經審核通過的項目，避免低品質農場文污染筆記本知識庫。
3. **來源勾選遺漏**：
   - ⚠️ 錯誤：在對話面板生成講義時，左側來源面板中部分重要來源未被勾選。
   - ✅ 正確：生成講義前，檢查左側來源清單，確認本節所需來源之核取方塊均已打勾。
4. **已存記事的修改限制**：
   - ⚠️ 注意：透過「儲存至記事」保存的回答卡片在 NotebookLM 中為唯讀狀態。若需後續編輯，可點擊卡片右上角 `...` 選擇「匯出至 Google 文件」或手動複製到外部編輯器。
